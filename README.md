## 📝 Project Overview

**Panto Furniture** is a modern **E-commerce Website** built with **React, Tailwind CSS, and Vite**.  
It showcases furniture products with interactive product carousels, routing, and user-friendly design.  
This project demonstrates frontend development skills and responsive UI design for a commercial website.

---

## 🚀 Tech Stack

- ⚛️ **React 18**  
- 💅 **Tailwind CSS 3**  
- ⚡ **Vite 5**  
- 🎠 **Swiper.js** – Product carousel  
- 🛎️ **SweetAlert2** – Alerts & notifications  
- 🔣 **React Icons** – Icons  
- 🔗 **React Router DOM 6** – Routing & navigation
